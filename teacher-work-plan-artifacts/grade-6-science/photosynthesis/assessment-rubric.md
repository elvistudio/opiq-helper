# Фотосинтез: аналитическая рубрика

## Статус и принцип оценивания

Самостоятельно составленная рубрика для внутреннего ревью. Она не подтверждает готовность к классу, публикации или эффективность. Предметный результат на русском и свидетельство эстонской языковой поддержки оцениваются раздельно: слабый эстонский не уменьшает научный балл при корректном русском объяснении.

## Safety gate

До предметного решения проверьте безопасность и честность данных. Небезопасное обращение, касание электрического оборудования мокрыми руками или при проливе, намеренная проба раствора, выпуск аквариумного растения в природу или придуманные данные запрещают безоговорочно положительное решение о практическом выполнении. Учитель фиксирует остановку, обеспечивает безопасность и решает, что можно переоценить без повторного риска.

## Предметная шкала

Для каждой строки используйте уровни 0–3.

| Измерение | 3 — уверенно | 2 — в основном | 1 — частично | 0 — нет свидетельства |
|---|---|---|---|---|
| Гипотеза и переменные | Проверяемая гипотеза; верно названы независимая, зависимая и существенные контролируемые переменные | Одна небольшая неточность | Несколько смешанных переменных | Переменные не определены |
| Контролируемая процедура | Соблюдены 1.0 g/L (1,0 г/л), 200 мл, 8 ± 1 см, 20 см, две акклиматизации по 5 минут, три минутных интервала и crossover | Одно условие неясно, но сравнение остаётся интерпретируемым | Несколько условий нарушены; нужна сильная оговорка | Сравнение недействительно |
| Качество наблюдений | Записи полные, честные, разделяют 0 и «не поддаётся подсчёту», температура отслеживается | Есть небольшие пропуски | Данные неполны или правило подсчёта менялось | Данные придуманы или отсутствуют |
| Расчёты | Верные суммы, делители, средние и разность с единицами | Одна вычислительная ошибка при верном способе | Способ частично понят | Расчёт не выполнен |
| Вывод по свидетельствам | Использует собственные средние, сравнивает условия и ограничивает вывод установкой | Есть данные и направление, но слабая оговорка | Вывод слабо связан с данными | Данные игнорируются или заявлена универсальность |
| Ограничения и надёжность | Называет не менее двух факторов и предлагает повтор или лучшее измерение | Одно существенное ограничение и улучшение | Ограничение названо без связи с выводом | Ограничений нет |
| Полное объяснение по-русски | Связно объясняет модель фотосинтеза, метод, данные и границы | Основная наука верна, ответ немного неполон | Есть существенная научная неточность | Объяснение отсутствует |

Предметный максимум: 21 балл. Локальную интерпретацию баллов определяет учитель после ревью; рубрика сама не задаёт readiness-порог.

## Эстонская языковая поддержка — отдельно

| Свидетельство | Выполнено | Частично | Пока нет |
|---|---|---|---|
| Использует 3–4 коротких предложения | | | |
| Уместно использует часть терминов fotosüntees, valgus, süsinikdioksiid, vesi, hapnik, gaasimull | | | |
| Говорит, что пузырьки — kaudne näitaja, и предлагает повтор | | | |

Поддерживаемая модель: «Fotosüntees vajab valgust, vett ja süsinikdioksiidi. Ereda valguse käes nägime rohkem / vähem gaasimulle. Gaasimullide arv on ainult kaudne näitaja. Katset tuleb korrata.» Это самостоятельно составленная языковая поддержка, не свидетельство устного задания цифрового учебника.

## Обязательные научные границы

Положительное предметное решение требует отсутствия прямых неверных утверждений:

- видимые пузырьки — косвенный показатель выделения газа, не объём кислорода;
- пузырёк не гарантированно состоит только из кислорода;
- число пузырьков не является точным измерением скорости фотосинтеза;
- опыт не измеряет образование глюкозы, здоровье, биомассу или долгий рост;
- одно сравнение не устанавливает универсальный причинный закон;
- температура, состояние побега, растворённые газы, концентрация, подсчёт и акклиматизация могут влиять на результат;
- для более сильного вывода нужны повторы и более точные измерения;
- фиксированного универсально правильного числа пузырьков нет.
