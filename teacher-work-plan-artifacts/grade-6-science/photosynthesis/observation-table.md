## Проверка качества сравнения

Отметьте «да», «нет» или «неизвестно».

| Условие качества | Ответ |
|---|---|
| Одинаковый объём: по 200 мл | |
| Сопоставимая длина побегов: 8 ± 1 см | |
| Одинаковое время: три интервала по 1 минуте в каждом раунде | |
| Яркое расстояние: 20 см | |
| Одинаковый раствор 1.0 g/L (1,0 г/л) | |
| Одинаковое правило подсчёта | |
| Побеги обменялись условиями | |
| Разница температуры не больше 2 °C | |
| Растения не повреждены | |
| Наблюдения не придуманы | |

Если хотя бы одно важное условие нарушено, вывод надо ограничить или сравнение признать недействительным.
